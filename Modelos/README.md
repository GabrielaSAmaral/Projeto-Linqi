# 🧠 Modelos selecionados

Esta pasta reúne os materiais relacionados à modelagem para cada loja e curva:

  - 💻 `lgbm_loja_curva` — Notebook com todas as etapas utilizadas na construção dos modelos selecionados.  
  - 📝 `melhores_parametros` — Documento com os melhores parâmetros do LGBM para cada combinação de loja e curva.  
  - 📁 `\predicoes` — Pasta contendo os arquivos com os resultados das predições geradas.
